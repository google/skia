Debugging in Chrome DevTools

    
    
      
  1. 
        Build dm for wasm in debug mode:
        
    target_cpu = "wasm"
is_debug = true
    
      
    2. 
      
  2. 
        Serve this page and the build, then open the printed URL:
        
    tools/wasm/serve_debugger.py --build out/wasm
    
      
    3. 
      
  3. 
        (Required) Install the
        
          C/C++ DevTools Support (DWARF)
        extension. Without it, DevTools only shows wasm disassembly.
      
    4. 
      
  4. 
        Open DevTools, go to the Sources tab and find the C++ file to debug under the
        file:// node in the left panel. It may take a minute to appear while the
        debug info is loaded.
      
    5. 
      
  5. 
        Set your breakpoint, then click Run. Click Run again to start a new run.
        Note: greyed-out line numbers cannot have breakpoints on them.
      
    6. 
      
  6. 
        To stop where dm crashes (e.g. failed SkASSERT), turn on
        Pause on uncaught exceptions in the source tab breakpoint pane.
      
    7.
